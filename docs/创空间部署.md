# 创空间部署（W4）

## 1. 准备
- 魔搭账号已实名、已绑定阿里云（API-Inference 要求）
- 本仓库根目录即创空间代码根：`app.py` 是入口，`requirements.txt` 装依赖

## 2. 新建创空间
1. 登录 modelscope.cn → 顶部「创空间」→ 新建
2. 名称：`lighthouse-seventh-night`（与 GitHub 仓库同名）
3. 可见性：公开
4. SDK：Python；硬件：CPU 2C8G（默认够用，规则层不占 GPU）
5. 创建后得到创空间的 Git 地址（形如 `https://www.modelscope.cn/studios/<用户名>/lighthouse-seventh-night.git`）

## 3. 推代码
```bash
git remote add studio https://oauth2:<访问令牌>@www.modelscope.cn/studios/<用户名>/lighthouse-seventh-night.git
git push studio master
```
注意：Git 用户名必须写 `oauth2`，用账号名 + 令牌会被拒（实测）。也可在创空间页面上传压缩包。

## 4. 配置密钥（不要写进代码）
在创空间「设置 → 环境变量 / Secrets」里加：
```
LLM_PROVIDER=modelscope
MODELSCOPE_API_KEY=ms-xxxx
MODELSCOPE_API_BASE=https://api-inference.modelscope.cn/v1
MODELSCOPE_MODEL=Qwen/Qwen3.8-Flash-Next
```

## 5. 启动
- SDK 选 Gradio 时平台直接 `python3 app.py`，`app.py` 必须是 Gradio 入口（本仓库已是）
- 平台当前 SDK 版本 6.29.1，`requirements.txt` 已锁 `gradio==6.29.1`，避免前后端版本不匹配卡在「加载中」
- 如需 FastAPI 版网页，本地运行 `uvicorn app_fastapi:app --port 7860`

## 5.1 部署后自检
- `GET /openapi/v1/studios/{o}/{r}` → Status=Running
- 打开 https://modelscope.cn/studios/mayi140611/lighthouse-seventh-night ，输入一句话，应看到 NPC 回复且「回合 1 · 模型 modelscope」

## 6. 验收
- 首页能打开，点提示按钮能收到 NPC 回复
- 「规则层日志」能看到提案 vs 采纳
- 断网/额度耗尽时，NPC 用预置台词兜底，页面不白
- 连打 10 轮不报错，单轮 <6s

## 已知边界
- 无鉴权，仅作公开演示；不要放任何私密数据
- 会话存内存，创空间重启即清空（存档仅在本地 `saves/`，线上不持久化）
- 线上模型费用走魔粒，演示前确认余额
